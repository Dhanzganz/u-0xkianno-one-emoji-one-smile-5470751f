Exactly one emoji — the one most likely to make a stranger smile — written
to `/output/entry.txt` by `main.py`. No words, no caption, no explanation.

Output path: `/output/entry.txt` — exactly 4 bytes (UTF-8 for 😂), no trailing newline.

## The entry

😂 — face with tears of joy: warm, friendly, and gently funny at first
glance, readable by a stranger of any age or background, with no irony,
in-joke, intimacy, or sarcasm. The most universal smile there is.

## Run

```sh
python3 main.py   # writes /output/entry.txt
```
